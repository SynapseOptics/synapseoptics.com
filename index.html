Optical design tools for engineers and AI agents

Modern lens design software with open APIs from day one — a CLI, a programmatic interface, and an MCP server so AI agents can drive a real ray tracing optical-design tool.

What we build

Optical-design software built around how engineers and AI agents work today: capable enough for serious design work, fully scriptable through a CLI and programmatic API, and ready for AI agents through an open MCP server.

Modern stack

Cross-platform desktop application built on Avalonia and .NET 8 with a native C++ ray tracer. Runs on Windows, Linux, and macOS.

Open APIs

Every workflow available in the GUI is also available via the CLI, the programmatic API, or the MCP server. The GUI, CLI, and MCP server source is MIT-licensed.

Affordable, perpetual

One-time purchase, two-machine activation, free LensHH-LT for students and academics. No subscriptions.
