What we build

Optical-design software built around how engineers and AI agents work today: capable enough for serious design work, fully scriptable through a CLI and programmatic API, and ready for AI agents through an open MCP server.

Modern stack

Cross-platform desktop application built on Avalonia and .NET 8 with a native C++ ray tracer. Runs on Windows, Linux, and macOS.

Open APIs

Every workflow available in the GUI is also available via the CLI, the programmatic API, or the MCP server — all under the MIT license.

Affordable, perpetual

One-time purchase, two-machine activation, free educational licenses for students and academics. No subscriptions.

The LensHH family

Two editions on a shared engine. Start with LT; upgrade to Pro when your workflow needs tolerancing, multi-config, environment, and coatings.
